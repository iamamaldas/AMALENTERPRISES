# 🚗 AMAL ENTERPRISES

### Auto Spare Parts & Industrial B2B Sourcing Platform

---

## 📌 About the Project

**AMAL ENTERPRISES** is a professional **B2B Sourcing Platform** designed to connect Auto Garages, Workshops, and Factories with genuine spare parts suppliers. 

The platform features a **built-in Quotation System** that allows users to:
- ✅ Select their role (Garage / Supplier / AMAL ENTERPRISES)
- ✅ Fill in part details (Category, Name, Quantity, Price, Specification)
- ✅ Generate professional quotations (Final or Negotiable)
- ✅ Share quotations instantly via **WhatsApp**
- ✅ Save Final Quotations to **Google Sheets** and generate PDFs

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Icons:** Font Awesome
- **Backend:** Google Apps Script (for Google Sheets & PDF generation)
- **Hosting:** GitHub Pages
- **Communication:** WhatsApp API (via `wa.me` link)
